Smaran Locker

Lock a note or a file so only one username can open it. You need no account to lock. The other person opens it with their username and password from any app with Smaran login. No wallet, no SOL, no server.

Send the saved .locked.json file any way you like: chat, email, a USB stick. Only that username's password opens it. Anyone can lock things for anyone, so the file does not prove who sent it.


      
    

    
Your password stays on this device. Opening works even offline with the password you had when the file was locked.

  


  
Part of Smaran, on Solana Devnet and MagicBlock. Devnet demo: a lost password cannot be reset, and nobody can open your files without it.
