What happens next?

1. Choose a job

Decide exactly what the agent is allowed to do.

2. Approve permission

Smaran asks you to sign the permission. Your private key is never shared with the agent.

3. Check the action

A separate agent key signs its proposed work. A verifier checks both signatures and the limits.

Step 2

What may your agent do?

The agent receives its own signing key, never your Smaran key. Every grant is bound to that agent key.

The Smaran window shows the exact signed message. A new temporary agent key is generated for this session.

Step 3

Try a permitted action

The agent prepares a simple local result. It cannot send emails, access accounts or call external tools. The proof is signed by its separate key.

Check a signed action

Paste an exported proof to verify the Smaran owner's signature, the agent's signature, the permitted job and expiry. Verification does not require signing in.

A valid signature does not establish that an external task was executed. This offline check cannot establish current revocation or globally enforced usage counts.
